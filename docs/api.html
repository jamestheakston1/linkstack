LinkStack Open API

No keys required. Connect your apps to the LinkStack ecosystem instantly.

Primary Endpoints

GET /public-api?handle={username}

Full Profile Data

Returns display name, bio, verified status, links array, and social handles.

JavaScript Example

fetch('https://xcicvuqdoztxhidwdmlc.supabase.co/functions/v1/public-api?handle=james')
  .then(res => res.json())
  .then(data => console.log(data));

Response Preview

{ "handle": "james", "display_name": "James", "links": [...] }
